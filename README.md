# Rhydence downloads

Windows installers and release notes for Rhydence, a personal planning and focus app.

**The first signed tester release is being prepared.** There is no public installer available here yet.

When a release is available, its installer will appear under [Releases](https://github.com/savuiux/rhydence-downloads/releases). Install the first signed release once to enable future in-app updates. Rhydence will let you choose when to restart and install an update.

This repository contains distribution files only. It does not contain Rhydence’s application source code or user records.
