# Rhydence downloads

A personal planning and focus app for Windows 10/11 (64-bit).

## Install Rhydence

1. Open [the latest release](https://github.com/savuiux/rhydence-downloads/releases/latest).
2. Under **Assets**, download **Rhydence-Setup-0.1.4-x64.exe** (or the newer version shown).
3. Run the installer and open Rhydence. No GitHub account is needed.

Existing preview users: install this tester release once to enable in-app updates. Your existing tasks, notes, preferences and history are kept.

## Get updates

Rhydence checks for updates after launch and periodically while open. You can also choose **Preferences → App updates**. New versions download in the background; choose **App updates** again to **Restart and install** when ready. Save open edits first. Active focus sessions and recordings postpone installation.

The `.blockmap` and `latest.yml` assets support the updater; you only need the `.exe`.

## Early tester build

This build does not have a Windows publisher certificate, so Windows may show an **Unknown publisher** or **SmartScreen** warning. Update downloads are verified using Rhydence’s embedded release key and installer checksums. This does not remove Windows security warnings.

This public repository contains distribution files and release notes only. It does not contain Rhydence’s source code or user records.
